EcoRouter
Stanford CS 153: Frontier Systems

LLM Agentic Carbon Scheduler

As AI scales, data center energy constraints are becoming the primary bottleneck. EcoRouter is a simulated autonomous agent that acts as a global infrastructure manager, dynamically routing compute workloads to regions powered by the greenest energy.

View on GitHub Launch Dashboard

Digital Twin

Simulates a live, fluctuating global cloud network with real-time carbon intensity (gCO₂/kWh) across multiple data center regions.

LLM Multi-Agent Brain

Utilizes LLM Function Calling to evaluate job queues, check grid status, and autonomously reason about optimal routing.

📊

Live Telemetry

A Streamlit dashboard visualizing the agent's real-time decisions and calculating theoretical carbon saved against a baseline scheduler.
